How TypeVector Tournaments Work

Blueprint Lifecycle

Events follow an explicit, audited state machine: DRAFT → PUBLISHED → REGISTRATION_OPEN → CHECK_IN_OPEN → LIVE → COMPLETED → RESULTS_PUBLISHED.

Registration is atomic and capacity-safe. In live rounds, deadlines are synchronized and strictly server-observed. No individual participant deadline extensions are permitted.
