Competition Rules & Scoring Principles

Transparent, mathematically reproducible guidelines governing TypeVector Arena practice and ranked tournament play.

Formula: arena-score-v1

Tournament Scoring System

Official scores in TypeVector Arena are derived exclusively on the backend from accepted WebSocket input batches and authoritative server elapsed time.

Score = [Net WPM × Accuracy Ratio × Weight] + Completion Bonus
  • Completion Gating: Incomplete attempts receive a maximum score cap of ≤ 699 points. Exact completion of the full challenge text unlocks scores ≥ 700 points.
  • Canonical Units: Typing units are measured as Unicode Extended Grapheme Clusters (not raw UTF-8 bytes). Code challenges preserve exact whitespace, tabs, and LF line breaks.
  • Zero Client Authority: Client-side metrics displayed during a round are previews labeled Local until validated and committed by the server.
