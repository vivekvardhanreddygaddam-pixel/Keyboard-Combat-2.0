Server-Authoritative Typing Arena for Competitions & Mastery.

TypeVector Arena is an independent typing-practice and esports tournament platform. Built with millisecond-level WebSocket sequence fencing, deterministic Unicode canonicalization, and zero client-side score authority.

Core Architectural Invariants

Every competition outcome is backed by durable relational evidence in PostgreSQL. Redis is strictly non-authoritative.

Durable Input ACK

PostgreSQL

Input batches are committed to PostgreSQL within an atomic transaction updating the attempt text projection and watermark. An INPUT_ACK is issued only after durable database commit.

Deterministic Scoring

arena-score-v1

Scores are calculated server-side using fixed-point integer arithmetic and pinned Unicode extended grapheme cluster segmentation. Client browsers cannot submit scores.

Fair Integrity Review

Human Review

Integrity signals are evidence flags for human judges, never automatic disqualifications. Dual approval is enforced for high-impact decisions with complete audit logging.
